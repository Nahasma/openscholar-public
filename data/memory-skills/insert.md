Skill: Insert New Memory
Purpose: 从当前文本中捕获尚未存在于记忆中的新的、持久的事实。
When to use:
- 文本引入了值得存储的新事实、事件、计划或上下文
- 信息是稳定的，且后续可能有用
How to apply:
- 与已检索的记忆对比以避免重复
- 将不同的事实拆分为独立条目
- 保持每条记忆简洁且具体
Constraints:
- 跳过琐碎的、短暂的或推测性的内容
- 不要更新或删除现有记忆
Action type: INSERT only.
