Skill: Update Existing Memory
Purpose: 当新信息补充或修正已有记忆时，合并更新。
When to use:
- 新文本提供了关于已知实体/事件的更多细节
- 已有记忆信息过时需要更新
How to apply:
- 指定要更新的记忆索引
- 将新旧信息合并为一条更完整的记忆
Constraints:
- 只更新直接相关的记忆
- 保留原有信息，除非被新信息明确否定
Action type: UPDATE only.
